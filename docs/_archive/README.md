# Archivo (documentacion historica)

Estos documentos pertenecen a la **fase de diseno inicial** del proyecto
(junio 2026). Se conservan como referencia historica pero **ya no son la fuente
de verdad**: fueron superseded por la implementacion real y por la documentacion
activa en `docs/` (ver `CLAUDE.md` seccion 7).

No estan enlazados desde la documentacion activa y sus referencias cruzadas
internas pueden apuntar a rutas antiguas. Para el estado actual del sistema usar:

- Arquitectura: `docs/architecture.md`
- Sistema visual: `docs/frontend/DESIGN_SYSTEM_VISION.md`
- Vision del rediseno: `docs/frontend/FRONTEND_VISION.md`
- Roadmap del rediseno: `docs/frontend/IMPLEMENTATION_PLAN.md`
